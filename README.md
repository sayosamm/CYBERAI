# AI-Powered Threat Detection and Mitigation System

## Overview
The **AI-Powered Threat Detection and Mitigation System** is an innovative cybersecurity solution designed to identify and mitigate AI-driven cyber threats in real-time. This project leverages advanced machine learning algorithms to detect phishing emails and anomalies in network traffic, providing a robust defense against evolving digital threats.

---

## Features
- **Phishing Detection API**:
  - A real-time email classifier to distinguish phishing emails from legitimate ones.
  - Exposes functionality via a REST API for easy integration with business systems.
- **Network Anomaly Detection**:
  - Identifies unusual patterns in network traffic using advanced ML models.
  - Detects potential cyber-attacks and other malicious activities.
- **Interactive Dashboard**:
  - Visualizes detected threats and network anomalies.
  - Provides actionable insights and trends in real-time.
- **Scalable Architecture**:
  - Designed for deployment on cloud platforms (AWS, Heroku).

---

## Tech Stack
- **Programming Languages**: Java
- **Libraries and Frameworks**:
  - Machine Learning: Scikit-learn, TensorFlow
  - API: Flask
  - Dashboard: Streamlit, Plotly
- **Tools**:
  - PyShark for real-time packet capture
  - Pandas and NumPy for data manipulation
- **Deployment**: AWS, Heroku, or Docker
